## ۲. راه‌حل‌های اسکن QR Code و باز شدن دیالوگ اهدا

برای تجربه کاربری روان، **دو سناریوی موازی** در فلاتر پیاده‌سازی می‌شود:

### راهکار الف: اسکن مستقیم از داخل اپلیکیشن (In-App Scanner)
1. کاربر در صفحه قفسه یا صفحه اصلی اپ روی آیکون دوربین/اسکن (`ScanQrButton`) کلیک می‌کند.
2. صفحه `ScanQrScreen` با استفاده از پکیج `mobile_scanner: ^5.2.3` (که در پروژه نصب است) دوربین را باز می‌کند.
3. به محض تشخیص بارکد کتاب (مثلاً `TK-8492` یا آدرس کامل `https://tafakormag.ir/b/TK-8492`):
   - کنترلر اسکن متوقف شده و صفحه دوربین بسته می‌شود (`Navigator.pop`).
   - بلافاصله متد `showModalBottomSheet` فراخوانی می‌شود و ویجت `HandoverBottomSheet` با اطلاعات کتاب بالا می‌آید.

### راهکار ب: اسکن از طریق دوربین گوشی بدون باز بودن اپ (Deep Linking / App Links)
1. کاربر دوربین اصلی اندروید/آیفون را جلوی QR کد کتاب می‌گیرد و روی لینک `https://tafakormag.ir/b/TK-8492` می‌زند.
2. به دلیل تنظیم بودن `App Links / Intent Filter` در اندروید، اپلیکیشن `tafakor_shop` باز می‌شود.
3. روتینگ پروژه (`go_router: ^17.4.0`) مسیر `/b/:code` را شناسایی می‌کند:
   - در صورت لاگین بودن: مستقیماً `HandoverBottomSheet` را روی صفحه اصلی باز می‌کند.
   - در صورت عدم لاگین: ابتدا صفحه احراز هویت سریع (OTP با شماره تلفن) را نشان داده و سپس دیالوگ را باز می‌کند.

## ۳. مراحل داخلی باتم‌شیت اهدا (`HandoverBottomSheet`)

این دیالوگ به صورت یک فرم چندمرحله‌ای (Stepper / Multi-step Sheet) بدون خروج از صفحه عمل می‌کند:

```
[مرحله ۱: پیش‌نمایش کتاب]
┌───────────────────────────────────────┐
│ ✕ بستن                                │
│ [عکس جلد]  نام کتاب: تاریخ طبری        │
│           نویسنده: محمد بن جریر طبری   │
│           موجودی قفسه شما: ۳ جلد       │
│                                       │
│ [دکمه مشکی تمام‌عرض: «اهدا می‌کنم»]    │
└───────────────────────────────────────┘
                  │
                  ▼ (با کلیک روی اهدا)
[مرحله ۲: اطلاعات گیرنده و تعداد]
┌───────────────────────────────────────┐
│ ← بازگشت به مشخصات                    │
│ تعداد جلد اهدایی:  [ - ]  (۱)  [ + ]   │
│                                       │
│ شماره موبایل گیرنده: [ ۰۹۱۲...      ] │
│                                       │
│ [دکمه مشکی: «تایید و ارسال هدیه»]      │
└───────────────────────────────────────┘
```

- با زدن «تایید و ارسال هدیه»: درخواست `POST /api/v1/marketplace/shelf/donate-to-phone/` ارسال شده و پس از موفقیت، پیامک کاوه‌نگار برای گیرنده فرستاده می‌شود.
