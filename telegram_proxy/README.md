# راهنمای فعال‌سازی ماژول بای‌پس فیلترینگ تلگرام (Telegram Bypass Relay)

این ماژول برای سرورهای داخل کشور که **دسترسی مستقیم به سرورهای تلگرام ندارند** طراحی شده است. این ماژول از تکنیک Domain Fronting با استفاده از زیرساخت گوگل (Google Apps Script) و کلادفلر (Cloudflare Workers) استفاده می‌کند تا ارتباط ربات و کدهای تأیید تلگرام شما را بدون اختلال و با امنیت بالا فراهم کند.

---

## 🛠️ مراحل استقرار و راه‌اندازی

### مرحله ۱: استقرار Cloudflare Worker (مقصد نهایی)
1. وارد پنل کاربری کلادفلر خود شوید.
2. از منوی سمت چپ به بخش **Workers & Pages** رفته و روی **Create Worker** کلیک کنید.
3. نامی برای ورکر خود انتخاب کنید و دکمه **Deploy** را بزنید.
4. روی **Edit Code** کلیک کنید، تمام کدهای پیش‌فرض را پاک کرده و محتوای فایل [`worker.js`](file:///f:/tafakor/telegram_proxy/worker.js) را قرار دهید و **Save and deploy** را بزنید.
5. به صفحه مدیریت ورکر بازگشته و از تب **Settings** وارد بخش **Variables** شوید.
6. یک متغیر محیطی (Environment Variable) جدید اضافه کنید:
   * **Name**: `RELAY_TOKEN`
   * **Value**: یک توکن تصادفی و طولانی بنویسید (مثال: `SecretToken12345!`). این توکن مانع سوءاستفاده افراد متفرقه از ورکر شما می‌شود.
7. آدرس ورکر خود را کپی کنید (به عنوان مثال: `https://telegram-relay.username.workers.dev`).

---

### مرحله ۲: استقرار Google Apps Script (بای‌پس فیلترینگ)
1. به سایت [script.google.com](https://script.google.com) رفته و روی **New Project** کلیک کنید.
2. کدهای پیش‌فرض را پاک کرده و کدهای فایل [`gas.js`](file:///f:/tafakor/telegram_proxy/gas.js) را قرار دهید.
3. در کدهای بالای صفحه:
   * مقدار `RELAY_TOKEN` را **دقیقاً** مشابه توکنی که در کلادفلر تعریف کردید قرار دهید.
   * مقدار `CFW_URL` را برابر با **آدرس ورکر کلادفلر خود** بگذارید.
4. از بالا سمت راست روی دکمه **Deploy** و سپس **New deployment** کلیک کنید.
5. روی آیکون چرخ‌دنده کلیک کرده و نوع آن را **Web App** انتخاب کنید:
   * **Execute as**: `Me (your-email@gmail.com)`
   * **Who has access**: `Anyone` (برای برقراری اتصال پروکسی، این گزینه الزامی است؛ امنیت توسط توکن مشترک تضمین می‌شود).
6. دکمه **Deploy** را بزنید و دسترسی‌های لازم گوگل را تایید کنید.
7. آدرس ارائه شده **Web App URL** را کپی کنید (به عنوان مثال: `https://script.google.com/macros/s/XXXXXX/exec`).

---

### مرحله ۳: تنظیم متغیرهای محیطی مونو ریپو
حالا کافیست آدرس‌ها را در فایل `.env` سراسری ریشه پروژه تفکر وارد کنید:

```ini
# فعال‌سازی بای‌پس پروکسی تلگرام
USE_PROXY_RELAY=true

# آدرس گوگل اسکریپت که در مرحله ۲ کپی کردید
GAS_URL=https://script.google.com/macros/s/XXXXXX/exec

# توکن امنیتی مشترک بین سرور، گوگل و کلادفلر
RELAY_TOKEN=SecretToken12345!

# در صورتی که داکر روی سرور ایران اجرا می‌شود، این متغیر را فعال کنید:
TELEGRAM_API_URL=http://telegram_proxy:8080/bot
```

سپس سرور تفکر را با پروفایل `proxy` راه‌اندازی کنید تا کانتینر محلی پروکسی نیز به همراه سایر سرویس‌ها لود شود:
```bash
docker compose --profile proxy up --build -d
```
ربات تلگرام و بخش ارسال پیامک اکنون بدون فیلترینگ و تحریم کار می‌کنند!
